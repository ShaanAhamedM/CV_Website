03 / Beyond the Terminal

Obsessed with how things work.

Whether it was taking apart gadgets as a kid, pulling all-nighters at 36-hour hackathons soldering microcontrollers, or obsessing over edge inference latency, engineering has always been about understanding mechanics and code from first principles.

Over the last few years, I’ve built assistive IoT hardware like the award-winning Vision Stick, autonomous rocker-bogie rovers under partial observability (POMDP), 3D spatial NeRF reconstructors, and real-time agricultural telemetry probes. Each project reinforced one core conviction: true engineering doesn't need multi-thousand-dollar cloud servers; it needs smart, elegant architecture.

We need builders who have heart, care deeply about craft, and can translate ambitious autonomy into working physical reality. If you only live once, this sure is a pretty cool time to build.
